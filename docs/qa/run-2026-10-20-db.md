## Как проверял
- **Живой API с авторизацией недоступен тестировщикам**: для валидного initData нужен настоящий токен бота, его чтение
  (и копирование прод-БД) запрещено политикой безопасности сессии. Поэтому:
  1. **Синтетическая БД** (`docs/qa/harness/seed.py`: 5 аккаунтов, 9 тредов DE/FR/PL, черновики, отправленные, закреплённый,
     продажа-детекция + 3 треда для `related`: тот же email под другим именем, то же имя с другим email). Две копии:
     одна под бэкендом из базы (`30fb4f4`), другая — из `a600ba1` (`git archive`, `init_db()` нового кода → миграции/индексы).
     Оба через `docs/qa/harness/serve.py` (без планировщика, LLM отключён), запросы — `docs/qa/harness/api_diff.py`
     с валидным initData от фейкового токена.
  2. **Живой прод** — только то, что не требует токена: `/health`, отказ без/с плохим initData, журнал после рестарта.
