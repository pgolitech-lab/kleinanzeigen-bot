## Нужно от api
1. `GET /pipeline` на тред:
   - `client_lang`;
   - `offer_eur`, `our_last_eur`, `floor_eur`, `ad_price_eur` (числа);
   - `is_hot`, `hot_reason`;
   - `tags`;
   - `is_late`, `from_app`, `maybe_same`.

   Верхнеуровнево `summary {waiting, waiting_client, sold_today_count, sold_today_eur, detected_pending}`.
2. `POST /threads/{id}/open`: в review те же числа сделки; `is_late` и `from_app` на событиях ленты.
3. `/send` и `/compose`: `kind` и `mode`, для `/compose` ещё `status`.
4. `/threads/{id}/sold` — фронт уже зовёт его, при 404 откатывается на `/messages/{id}/sold`.
5. B-02 в источнике: `db_threads.thread_events` `SENT_LIKE` включает черновики.
