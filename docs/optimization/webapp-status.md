## Подключено к api (2026-10-20, пять коммитов в opt/webapp)
1. Отмена отправки за 5 с (`/send delay_sec`, `/send/{id}/cancel`) — тред и «Разбор», `components/send.js`.
2. «✨ Все варианты» (`/variants`), «⚡ Быстрый ответ» (`/quick`, справка в «Аккаунтах»), «🔔 Напомнить» (`/followup`).
3. «Склад»: приход партией с предпросмотром (`/stock/receipt/parse` → `/stock/batches`, общая сумма делится сервером), `#/stock/types` (типы + стандартная себестоимость), комплект (`PUT …/kit`), «Не запчасть» (`…/non-stock`).
4. «Рынок»: `screens/market.js` (`#/stock/market`: дубли «снимите N из M», перевыкладывание с готовым текстом), листы «Цена и рынок» и «Как стать заметнее» в карточке товара.
5. Маршрут `#/send/<id>` (= `review`), `telegram_admin_chat_id` в настройках, 409 без причины — понятный текст.

Пробелы api: GET состава комплекта (`components` в `/stock/products/{id}`) и список скрытых товаров (`include_non_stock` в `/stock/products`) — на фронте пока счётчик и «заменит состав».
