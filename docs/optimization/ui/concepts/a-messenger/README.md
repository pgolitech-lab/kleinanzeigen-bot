# Концепция A — «Тёмный премиум-мессенджер»

**Питч.** Mini App ощущается как родной Telegram, только лучше: глубокие тёмные поверхности со стеклом
(backdrop-filter), акцентный градиент синий→фиолетовый, мягкие тени, «аврора» на фоне. Оператор живёт в
привычной модели «список чатов → чат», но каждый экран отвечает на два вопроса: *что ответить* и *не продешевить ли*.
Над чатом закреплена **полоса сделки**: цена / минимум / клиент / мы + цветная шкала (красная зона ниже минимума,
зелёная — от минимума до цены, маркеры предложений, пунктир — цена из черновика ИИ). Пузыри двуязычные: оригинал +
RU под ним, тап по пузырю меняет главный язык, кнопка в шапке прячет/показывает переводы. Черновик ИИ встроен у
поля ввода как пузырь «готов к отправке»: бейдж «DE ✓», RU-зеркало, одна большая кнопка «Отправить по-немецки».
Вау — в мелочах: аватар и имя «перелетают» из списка в шапку треда (View Transitions), отправленный текст
перетекает из черновика в ленту, свайп строки влево — «Отправить черновик / Жду / Продано».

## Что где
- `index.html` — оболочка; `style.css` — токены и компоненты; `app.js` — данные, рендер, жесты, переходы.
- Данные: `../_shared/mock.js` + локальные добавки в начале `app.js` (`EXTRA`, `CLIENT_X`, `LESSONS`,
  `FOUND_SALES`, `EVENT_MARKS`, `ROW_MARKS`).
- URL: `?screen=inbox|thread|client|sales`, `?theme=dark|light` (выставляет `--tg-theme-*` пресетом),
  `?select=1` — показать режим множественного выбора, `?shot=1` — без анимаций (для скриншотов).
- `shots/` — 6 устройств × 4 экрана, светлая тема на flip-main и fold-inner-land.

## Раскладки
- **Телефон (Fold внешний 280–412, Flip 412):** вкладки Чаты / Клиенты / Продажи; в треде вкладки скрыты,
  внизу — док с черновиком. На 280 px шкала в строке списка прячется, кнопка отправки — «Отправить / по-немецки ✓».
- **Fold внутренний 820×910:** 2 колонки (чаты | тред с полосой сделки). **910×820:** 3 колонки
  (чаты | тред | панель «Сделка» с большой подписанной шкалой + «Клиент» со статистикой, досье и предупреждением).
- **Flip Flex Window 306×340:** только последнее сообщение (RU) с ценой клиента, RU-зеркало черновика с бейджем
  языка, огромная «Отправить» и «Назад». Список — только «Ждут ответа».

## Функции (в т.ч. по дополнению владельца)
- Отправка в 3 этапа компактно: полоска этапов на карточке (этап 3 — проверено), «⋯» открывает этапы 1–2
  (перевести на язык клиента, переписать идею ИИ с пресетами, как есть, написать своё), «✎» — правка с живой
  проверкой языка. Кириллица → бейдж «RU ✕», кнопка выключена до галочки «Разрешаю отправить текст не на языке клиента».
- Множественный выбор (кнопка в шапке или долгое нажатие) → Закрепить / Жду / Продано; закреплённые наверху секции.
- «Жду» — свайп или массово, секция «Жду · отложено». Ручная продажа («+ Продажа»), «Найденные продажи» с
  Подтвердить/Отклонить и отменой.
- Теги и заметка в карточке клиента; **досье** (сводка + когда писал, о чём, какие цены);
  **«Возможно, тот же покупатель»** — плашка в чате, в карточке клиента («Это он / Разные»), в боковой панели и
  значок в строке списка.
- **Уроки** — значок книги с числом в черновике, шторка «плохо → правка оператора».
- Пометки писем: «из приложения» (значок телефона в пузыре и в списке), «запоздало · 6 ч» (янтарный).

## Ограничения и риски для реального MA
- View Transitions есть в Chromium (Android Telegram), в iOS WebView — с Safari 18; без поддержки — CSS-фейд.
- `backdrop-filter` на слабых Android может проседать при скролле длинного списка — держать стекло только на
  шапке/доке/вкладках, не на строках.
- Свайп конфликтует с системным «назад» жестом края экрана и со свайпом закрытия Mini App — нужен
  `TG.disableVerticalSwipes()` и мёртвая зона у краёв.
- Шкала требует `floor` и «наше последнее» в API треда (сейчас `ourLast` берётся из `deal_brief_json`).
- Проверка языка в прототипе — только кириллическая эвристика; в проде остаются `/lang-check` (Haiku) и 409-guard.
- Длинные немецкие тексты черновика обрезаются до 3–4 строк (тап «✎» показывает целиком) — нужен явный «ещё».
- Шрифт в скриншотах — DejaVu (шире Roboto); на устройстве запас по ширине будет больше.
