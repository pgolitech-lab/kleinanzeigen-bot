Save:
- POST /api/ma/messages/{id}/edit-ru {text}
- backend: claude.translate_only(target=client_lang) + db.update + _broadcast_card
- response: новый review payload (RU + back-translated DE)
- frontend: re-render pending-draft с обновлёнными значениями

Cancel: просто закрыть textarea, action-grid обратно

При tap [↻ Проверить снова]:
- POST /messages/{id}/lock/acquire
  - 200 → lock now ours, render action-grid
  - 409 → still locked, update remaining_min, banner stays

Action-grid в input-режиме

Edit-RU/DE/price/instruction — заменяют action-grid на pair [💾 Apply][✕ Отмена]. После Apply (или Cancel) — fresh re-render review payload (POST endpoint возвращает обновлённые поля), action-grid обратно.
