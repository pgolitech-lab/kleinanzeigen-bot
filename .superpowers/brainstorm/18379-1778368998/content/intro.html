Phase 3 — Review actions

Самая большая фаза. Сначала решим scope, потом UX-вопросы по review-карточке. Сюда полетят мокапы action-grid, edit-inline pattern, lock-конфликт.

Что в Phase 3 (по spec)

  • operator_lock рефакторинг — выносим _THREAD_LOCKS из telegram_bot.py в общий модуль
  • Lock endpoints: acquire/release
  • GET review payload: ru_client/ru_answer/de_answer/ru_translation/deal_brief/related/lock_state
  • POST send / skip / sold — финальные действия
  • POST regenerate {strategy: harder/softer/shorter/rephrase/no_haggle}
  • POST edit-ru / edit-de — правки текста с back-translation
  • POST price / instruction — кастомные регенерации
  • Review screen UI с action-grid, edit-inline textarea, состояниями (idle, edit-mode, lock-conflict)
  • Bot ↔ MA broadcast — после действий MA вызывает _broadcast_card
