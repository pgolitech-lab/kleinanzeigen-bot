6 экранов Mini App — навигация

Hash-routing: #/pipeline, #/review/123, #/thread/abc, #/autopilot/abc, #/client/foo@bar.com, #/settings. TG BackButton API синхронизируется с history.back().

Flow между экранами
                    ┌──────────────────┐
   bot DM нотиф ──► │   PIPELINE       │ ◄── Telegram menu button
                    │   #/pipeline     │
                    └────────┬─────────┘
                             │ tap thread
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
        ┌──────────┐   ┌──────────┐   ┌──────────────┐
        │  REVIEW  │   │  THREAD  │   │  AUTOPILOT   │
        │ /review  │◄─►│ /thread  │   │ /autopilot   │
        │   /N     │   │   /abc   │   │    /abc      │
        └────┬─────┘   └────┬─────┘   └──────┬───────┘
             │              │                │
             │ «📋 история» │ «📋 история»   │
             ▼              ▼                │
        ┌──────────────────────┐             │
        │   CLIENT HISTORY     │             │
        │  /client/email@x     │             │
        └──────────────────────┘             │
                                             │
                  ┌──────────────────────────┘
                  ▼
            ┌──────────┐
            │ SETTINGS │  ◄── из любого экрана через ⚙ в header
            │/settings │
            └──────────┘

Что важно

  • Pipeline = entry-point, первый что видит оператор когда тапает MA
  • Review и Thread — два угла одного треда: review = «что делаем сейчас» (карточка с действиями), thread = «что было» (лог); переключаются tab-ом
  • Autopilot экран нужен только пока тред в автопилоте; если не активен — кнопка «🚀 Запустить» прямо в Review
  • Client history — глубокая ссылка из related-warning блока
  • Settings — отдельный экран, доступ из header-а
